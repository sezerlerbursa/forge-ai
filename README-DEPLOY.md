# Forge AI v0.4 — Kurulum

## GitHub
Bu klasörün içeriğini `sezerlerbursa/forge-ai` repository'sinin köküne yükleyin.

## Vercel
`static` klasörü frontend'in köküdür. Vercel'de proje ayarlarında Output Directory olarak `static` kullanabilirsiniz.

## Gerçek AI üretimi
Bu sürüm mobil UI + API iskeletidir. `/api/edit` endpoint'i henüz gerçek bir FLUX/SDXL inference sağlayıcısına bağlı değildir. Gerçek üretim için bir GPU/model sağlayıcısı bağlanmalıdır.
